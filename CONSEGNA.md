# 🎯 FOCUS FLOW - DISTRIBUZIONE PER CAPOLAVORO

## 🚀 INIZIA QUI

Doppio click su: **`START_CAPOLAVORO.bat`**

Questo file menu ti guida passo per passo!

---

## 📁 File Principali per la Consegna

### 1️⃣ **START_CAPOLAVORO.bat** ⭐ PRINCIPALE
- Menu interattivo per tutto
- Non sbagliare nulla!

### 2️⃣ **BUILD_RELEASE.bat**
- Crea l'APK nel cloud
- Generato automaticamente
- Pronto per il download

### 3️⃣ **DOWNLOAD.html**
- Pagina per scaricare dal telefono
- Basta aprire nel browser
- Link diretti ai file

### 4️⃣ **GUIDA_CONSEGNA.md**
- Guida completa (come questo file)
- Leggi se hai domande

---

## ⚡ Flusso Veloce (5 minuti)

```
1. Doppio click: START_CAPOLAVORO.bat
2. Scegli "1 = Build APK"
3. Accedi a Expo (1 minuto)
4. Attendi il build (10-15 minuti)
5. Vai su: https://expo.dev/dashboard
6. Scarica l'APK
7. Installa sul telefono
8. Done! 🎉
```

---

## 📥 Dopo il Build

```

```

```

2. Invialo via Whatsapp/Email

```

## 📱 Installazione su Telefono

### Android:
1. Scarica il file `.apk`
2. Vai in Impostazioni → Sicurezza
3. Attiva "Installa da fonti sconosciute"
4. Clicca sul file APK
5. Installa!

### iPhone:
- Richiede TestFlight o App Store
- Più complicato, non consigliato per il primo test

## 🆘 Problemi Comuni

### "Errore nel build"
→ Controlla gli errori su https://expo.dev/dashboard/logs

### "App non si installa"
→ Prova a cancellare cache: Impostazioni → App → Focus Flow → Cancella

### "Porta non disponibile"
→ Riavvia il telefono o il PC

### "Login Expo non funziona"
→ Assicurati di avere internet
→ Crea account su https://expo.dev
